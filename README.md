# Dependencies

The Arduino code in this project uses [PinChangeInterrupt](https://github.com/NicoHood/PinChangeInterrupt) by NicoHood.

Follow the instructions here to install: https://docs.arduino.cc/software/ide-v1/tutorials/installing-libraries/.
