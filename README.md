# Welcome

This branch contains code written for the **Virtual League**, alongside a high-level overview.

## Files

- `robot.py`: code submitted to Student Robotics.
- `report.pdf`: brief overview of the Virtual League and the inner workings of the code.

## Installation

You can run the code we submitted to Student Robotics yourself. You will need the following software:

| Software | Version | Notes |
| --- | --- | --- |
| [Python](https://www.python.org/downloads/) | 3.11 | Also works with 3.9–3.12; not 3.13+ |
| [Webots](https://github.com/cyberbotics/webots/releases/tag/R2023b) | R2023b |  |
| [sbot_simulator](https://github.com/srobo/sbot_simulator/releases/tag/2025.1.1) | 2025.1.1 |  |

1. Install **Python 3.11** and **Webots R2023b**.
2. Download **sbot_simulator-2025.1.1** and unzip it.
3. Run `setup.py` – this will be in the folder you just unzipped.
4. Open the `zone_0` folder and replace the `robot.py` file there with the one from this branch.
5. Run `run_simulator.py` to open the virtual arena.

For a quick guide on using Webots, click [here](https://studentrobotics.org/docs/simulator/using_the_simulator). You can also use `readme.html` in the folder you unzipped.
